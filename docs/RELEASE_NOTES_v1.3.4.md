# v1.3.4：更新流程、深色对比度与按钮样式

- 将手动检查更新入口收敛到“设置 → 关于与更新”，避免重复入口和设置弹窗冲突造成的崩溃。
- 检查更新请求随设置窗口生命周期取消；关闭窗口后不再访问已销毁的界面。
- 更新完成后等待新进程报告启动就绪，再提交版本切换；启动失败时恢复旧文件并重新打开旧版本。
- 修正 Windows PowerShell 更新器的模块搜索路径和工作目录，避免升级重启后清理工作目录时失败。
- 调整深色模式下设置页标题文字的前景色，增强层级标题的可读性。
- 统一操作按钮圆角为 12px；照片卡片、详情操作和设置按钮沿用同一规则，边框卡片保持原有造型。

本地验证包括 57 项逻辑回归、6 项 Windows PowerShell 更新器场景、按钮样式源文件检查，以及桌面构建的版本与启动路径核对。自动检查不等同于人工逐项点击验收。
