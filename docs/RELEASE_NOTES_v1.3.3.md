# v1.3.3：Stable / Nightly 更新通道

- 更新发现统一读取本仓库 GitHub Releases。Stable 只读取正式稳定版；Nightly 读取独立每日预发行版本。
- 设置 → 关于与更新，新增通道选择与公益代理开关。Nightly 有不稳定风险，可主动切回 Stable；切换可能回退版本，不自动安装。
- 内置 `https://gh-proxy.org/` 为直连失败后的公开包备用下载通道，不接收照片、图库、登录令牌或 API 请求。关闭开关后仅直连。
- SHA256 以 GitHub 直接返回的校验信息为准；错误大小、损坏包、篡改包、错误发行通道/标签都拒绝安装。失败保留旧版本。
- 源码推送到 master 后，Action 自动编译并保存七天测试产物；每天北京时间 02:23 从最新 master 检查变化，有变化才发布 Nightly。Stable 仍需推送 `vX.Y.Z` 标签。
- Nightly 标签不可变，每个安装包附带通道、源码 commit、标签及版本信息。不会覆盖 Stable 的 latest 入口，也不重复安装同一个 Nightly。

公共代理不保证持续可用；GitHub API 限流时直接读取同仓库 Release 页面和 Release 资产作为备用；GitHub 全部直连路径不通则明确失败，不使用第三方提供的元数据冒充 GitHub。GitHub 定时任务可能延迟或因仓库长期无活动暂停。
既有安装器“此应用无法运行”的反馈尚缺实际报错文件路径与哈希，本次通道改造不代表该安装问题已定位。安装器仍未商业签名。
新增设置本轮已通过编译及逻辑测试，尚未进行完整人工点击验收。
