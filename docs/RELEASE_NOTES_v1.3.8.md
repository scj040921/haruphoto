### 新功能

- 地图相册可按需搜索地名。按回车或点击搜索提交，不会自动联想；搜索结果优先使用简体中文名称。选择结果可直接定位，放置照片时可把预览中的照片批次放到该地点。
- 搜索地点会把输入的地名发送给 OpenStreetMap Nominatim；照片、地点记录和批注仍只保存在本机。
- 地图操作界面和归属说明统一为简体中文。

### 地图文字说明

当前底图由 OpenStreetMap PNG 图块提供，图中文字已由底图服务渲染，无法在客户端强制翻译。地点搜索结果及应用界面使用简体中文；底图地名仍按图块实际包含的语言显示。

### 安装

安装版下载 `haruphoto-v1.3.8-Setup.exe`；便携版完整解压 `haruphoto-v1.3.8-portable.zip`。程序自带运行时，无需另装 .NET 或使用 CMD。
