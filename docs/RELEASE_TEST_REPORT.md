- 横图、竖图、方图预览与对应详情一致；放大按钮从适应切换至 125%，切换另一张恢复适应。

## 未覆盖范围

没有在无开发环境的全新 Windows 10/11 机器、ARM64、32 位系统、多种 DPI/显卡组合执行测试；没有穷举全部设置组合、2–4 图对比的所有组合、动画每一帧、系统分享/裁剪流程、所有图片格式或全程真实联网跨版本升级。
最终包新增的预览序号、居中读取错误提示与小尺寸取色采样已通过构建；该轮人工复核被用户按 Esc 中止，这三项未再做最终包的点击验证。上述实际界面结果来自此前同版本候选构建，不等同于对最终包所有改动的完整验收。
安装器尚未商业代码签名，SmartScreen 可能仍提示未知发布者。实际首次下载及安装应以朋友电脑反馈为最终兼容性验证。
自动化只能保证已执行用例通过，不能据此声明整个应用绝对没有 bug。
