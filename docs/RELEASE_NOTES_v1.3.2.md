# haruphoto v1.3.2

## 下载与安装

- 推荐：下载 `haruphoto-v1.3.2-Setup.exe`，直接双击安装，无需运行 CMD，也无需额外安装 .NET 或 VC++ 运行时。
- 便携版：下载 `haruphoto-v1.3.2-portable.zip`，完整解压后运行 `PhotoAlbum.exe`，不要只复制 EXE。
- 支持 Windows 10 1809+ / Windows 11 的 x64 系统；不支持 32 位 Windows。
- GitHub 自动生成的 Source code 是源码，不是安装包。
- 当前安装器未购买商业代码签名证书，Windows 可能提示未知发布者。请核对本仓库与 SHA256；本版本并未消除 SmartScreen 签名提示。

## 改进

- 保留原比例紧密瀑布流、缩放、切换动画、取色模糊背景和新版顶栏/底栏。
- 设置分区、搜索、保存/取消、分区重置及自定义外观方案；新增 2–4 张对比选片与同步缩放。
- 修复详情栏被胶片条挡住、远端缩略图空白、深色设置卡片和侧栏显示问题。
- 修复快速预览切换与关闭时的动画竞争、重复悬停事件、批量选择残留。
- 补齐预览序号和损坏图片提示；取色采用小尺寸采样，降低大照片的内存开销。
- 关闭自动扫描后不再监控文件夹，离线图片的元数据不会因普通保存丢失。
- 更新只提示不强制安装；可查看版本说明、取消下载。先下载并验证，失败保持当前应用运行；升级替换失败会回滚。
- 完善公开更新清单、SHA256、完整自包含包与发布前自动测试，避免朋友必须运行 CMD 安装。

## 验证边界

已在开发机使用独立临时图库执行界面回归，并测试下载安装器核心、损坏包拒绝及升级回滚。没有真实覆盖所有 Windows、DPI、显卡或无开发环境的全新电脑，不能承诺绝对没有 bug。详细范围见仓库 `docs/RELEASE_TEST_REPORT.md`。
