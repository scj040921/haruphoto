# v1.3.11 · 影像展厅与照片浏览

- 新增「影像展厅」。在「设置 → 方案与外观 → 界面风格」中切换，使用顶部导航、圆角玻璃工具栏和按比例排布的照片墙。宽窗口合并标题与工具，窄窗口自动分行。
- 照片查看器在窄窗口整理常用操作，幻灯片和胶片条开关可从「更多」找到，详情面板避开换片按钮。切换照片时保留过渡，正在加载的照片可先显示柔化预览。
- 改进照片操作按钮的键盘可达性，提高文件路径、筛选计数和玻璃菜单图标的可读性。界面动效遵循 Windows 和应用内的动画设置。
- 地图相册新增本地地点浏览，改进缩放、地点照片展开与从预览返回的位置衔接。底图加载失败时可以重试。
- 导入扫描支持取消。照片读取失败时可重试或跳过，后台扫描和元数据修改尽量保持正在浏览的照片与缩放状态。
- 优化图库滚动、缩略图驻留与地图缓存。安装包内含所需运行时，可直接运行安装程序。
