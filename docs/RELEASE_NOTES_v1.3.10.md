# v1.3.10 · 更清晰的图库与地图体验

- 重排图库搜索、筛选、分页和筛选摘要，避免窗口宽度变化时控件相互覆盖。
- 更新地图相册的操作栏、地点搜索、照片放置预览和地点照片卡片，布局更清楚且视觉更统一。
- 优化大图库收藏数量统计，改用增量计数，避免每次操作都重新扫描整本图库。
- 修复更新程序遇到安装目录被其他进程占用时的替换回退，并增强失败回滚保护。
- 保持地图位置和批注仅存于本地；照片文件本身不会因这些改动而被修改。

安装版下载 `haruphoto-v1.3.10-Setup.exe`；便携版请完整解压 `haruphoto-v1.3.10-portable.zip`。程序自带运行时，无需另装 .NET 或使用 CMD。
